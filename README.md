# Summit Training & Nutrition Website

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Important: connect the form

Open `src/App.jsx` and replace:

```txt
https://formspree.io/f/YOUR_FORM_ID
```

with your real Formspree form link.

Example:

```txt
https://formspree.io/f/abcdwxyz
```

Then commit and push to GitHub again.
